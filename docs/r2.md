# Penyimpanan Cloudflare R2

Disk `r2` menyediakan penyimpanan objek privat melalui adapter S3 Laravel.
Konfigurasi ini menyiapkan koneksi penyimpanan; formulir dan endpoint unggah bukti
PBI-07 belum dibuat. Metadata bukti tetap menjadi data aplikasi di TiDB.

## Pengaturan akun dan environment

Bucket `terangdesa-bukti` memakai Standard storage dan public access Disabled.
Kredensial R2 memakai Object Read & Write yang dibatasi ke bucket tersebut.
Salin variabel berikut ke `.env` lokal dan environment server:

```dotenv
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET=terangdesa-bukti
R2_ENDPOINT=https://ACCOUNT_ID.r2.cloudflarestorage.com
R2_REGION=auto
```

Isi Access Key ID dan Secret Access Key secara privat. Gunakan kredensial S3 R2,
bukan bearer API Token atau Global API Key Cloudflare. Endpoint menggunakan S3 API
yang ditampilkan Cloudflare, tanpa nama bucket pada path. Untuk bucket dengan
jurisdiction khusus, gunakan endpoint khusus yang ditampilkan dashboard.

`.env` dan kredensial tidak dimasukkan ke Git. Anggota lain menjalankan
`composer install` setelah mengambil kode dan mengisi environment masing-masing.
Default filesystem aplikasi tetap mengikuti pengaturannya sendiri; pemakai R2
memilih disk secara eksplisit dengan `Storage::disk('r2')`.

## Pemeriksaan koneksi

```powershell
php artisan config:clear
php artisan terangdesa:r2-check
php artisan terangdesa:r2-check --write-test
```

Perintah biasa menjalankan HeadBucket tanpa menulis data. Opsi `--write-test`
menyimpan objek teks kecil dengan nama UUID di `connection-checks/`, membaca dan
membandingkan isinya, lalu menghapus objek uji itu sendiri. Perintah hanya menghapus
objek unik yang dibuat percobaan tersebut. Jika cleanup gagal, hasil menyertakan
path objek untuk dibersihkan manual. Kode keluar 0 berarti seluruh pemeriksaan
berhasil; kredensial yang belum diisi menghasilkan status pending dan kode 1.
Tidak ada pembacaan atau penulisan database oleh perintah ini.

## Pemakaian oleh fitur berikutnya

```php
$path = Storage::disk('r2')->putFile('bukti-pengajuan/'.$pengajuanId, $uploadedFile);
$url = Storage::disk('r2')->temporaryUrl($path, now()->addMinutes(5));
```

Fitur pemanggil tetap harus memeriksa izin pengguna dan validitas gambar, menyimpan
path objek pada metadata bukti, dan menangani kegagalan penyimpanan metadata.
Simpan path permanen, bukan temporary URL yang akan kedaluwarsa. Untuk akses
melalui backend Laravel, CORS bucket belum diperlukan. Unggah langsung dari browser
ke R2 memerlukan rancangan CORS dan presigned upload terpisah.

Referensi: https://developers.cloudflare.com/r2/get-started/s3/
dan https://laravel.com/docs/12.x/filesystem.
